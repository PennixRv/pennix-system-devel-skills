# 裸机与 FreeRTOS 的时序及资源证据

- **按目标定义计时区间。** 分开外部触发、进入 ISR、ISR 结束或交接、任务／主循环取到事件、处理完成。记录对应事件标识、计时源、频率、分辨率、回绕和同步条件；不同计时源不能直接相减。平均循环间隔加 ISR 用时不是端到端上界。
- **覆盖可能拖慢的条件。** 依据项目的优先级、屏蔽、嵌套中断、队列积压或错误路径核对。GPIO 脉冲、可用计数器或现有记录只能衡量自己覆盖的时间点；日志、探针和测量频率也会扰动。只报告所覆盖的试验及最大观察值，期限保证还需采取项目适用的上界分析与覆盖证据。
- **分清预算和测到的用量。** 按匹配镜像的 map/ELF 核对链接区域、保留空间及加载地址与运行地址，区分 Flash、静态 RAM、堆和各类栈。FreeRTOS 任务栈高水位需核对接口单位和已运行路径，不代替 ISR 栈或未跑错误路径；裸机按实际栈布局核对。一次高水位不能证明可削减余量。

没有目标侧证据时，只说明静态结果与缺失的测量点。目标时钟及计数能力查芯片和端口文档；FreeRTOS 可查 [`uxTaskGetStackHighWaterMark`](https://www.freertos.org/Documentation/02-Kernel/04-API-references/03-Task-utilities/04-uxTaskGetStackHighWaterMark)。不默认连接探针、刷写或改变中断配置。
