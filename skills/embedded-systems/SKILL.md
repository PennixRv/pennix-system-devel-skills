# 裸机与 FreeRTOS

列出 MCU/板卡、编译器、芯片手册及 errata、RTOS 端口与配置、内存和时序预算。板卡或时钟不明时不猜寄存器和约束；先区分裸机主循环、ISR、DMA 与任务。

1. **划分运行责任。** 把时间敏感且必须在 ISR 处理的工作与可延后工作分开；注明事件丢弃、覆盖、排队和等待的策略。FreeRTOS 用目标端口的 ISR API 与优先级限制，不把普通任务 API 或固定 NVIC 优先级值照抄进中断。
2. **列缓冲区交接。** 明确 CPU、ISR、DMA 和任务谁何时可访问，完成条件、取消、超时和最后回收顺序。`volatile` 不是同步；按平台查缓存、内存顺序、对齐和中断屏蔽要求。不能用固定的全局开中断收尾来覆盖进入前的状态。
3. **对照资源和故障。** 检查栈、堆、静态区、链接布局和延迟预算。任务创建、队列满、DMA 失败或超时时给出资源状态及恢复。低功耗、看门狗和动态分配随系统目标和约束决定，不强制加设备策略。
4. **限于已有证据。** 代码和 map 文件可说明部分结构或大小，不能证明实测延迟、功耗或最坏时序。只有允许且具备目标时再建议验证，不默认连接、刷写、量测或把仿真当成真机。

输出约束、资源及执行上下文、失败与验证方案。FreeRTOS 调用以目标端口和项目源码为准，可对照 [FreeRTOS Kernel](https://github.com/FreeRTOS/FreeRTOS-Kernel)；芯片专有示例仅说明方法。
