# C/C++ 专题评测

分开核对选路、工程判断和实际工具可执行性。用 `python3 -B evaluations/case.py <id>` 只渲染合成请求；判据只由审查方用 `--rubric` 读取，不随提示发送。

| 场景 | 集合评测重点 | 确定性工具证据 |
| --- | --- | --- |
| `language-c-byte-view` | 不把协议字节当本机结构体；长度、对齐、对象类型、字节序和失败输出保全各自成立。 | 可移植字节解析夹具的对齐偏移、截断及输出保留。 |
| `language-cpp-slot-reuse` | 发布与再次占用分别有同步链；借用最后一次访问先于槽位释放。 | 正常 SPSC 夹具验证完成后复用；运行通过不证明所有调度及内存序正确。 |
| `language-target-clang-tidy` | 核对实际翻译单元、数据库、工作目录、参数和工具可用性；解析失败不得报零告警。 | 同一翻译单元用不同宏生成两份数据库，以 benign 诊断对照实际选择；宿主夹具不宣称测试了交叉 SDK。 |
| `language-asan-control` | 三段堆栈、工件匹配和执行覆盖归运行时诊断；不新增真实取证。 | 用无故障最小程序验证宿主插桩可运行；已有合成报告的判读另验，不制造真实漏洞。 |
